# Tide+ 1.0.8

Records everyone hears about, a Mythic everyone hears, and fish you kill are worth something. Install the same way: the jar in `mods/` on the server and every client (replaces 1.0.7).

## Server records
- The server now keeps its **heaviest fish of each kind**: who caught it, the weight and the quality.
- Beating one is announced to everyone, with a bell: "🏆 Tyler set the server record: ◆◆◆ Great Bluegill 3.4 lb (beat Gimli_Jr's 3.1 lb)". The catch card and your chat line say "Server record!".
- The first catch of a kind sets its record quietly, so the early days aren't all announcements. Records from before this update come from each player's journal when they next join.

## Mythic catches
- Everyone on the server now hears a Mythic's fanfare, not just people nearby.

## Fish you kill
- A wild fish killed for its drop now comes with a quality and a weight like a caught one, rolled at your fishing level. It tops out at Great: Trophy and Mythic fish only come from the rod. Killed fish don't give fishing XP or go in the journal.
