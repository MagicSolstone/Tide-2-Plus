# Tide+ 1.1.3

Install the same way: the jar in `mods/` on the server and every client (replaces 1.1.2).

## One word per stat
Every stat has a short name and its own colour, the same on tooltips, the rod panel, the Angling Table's stats panel and the journal:

| Was | Now |
|---|---|
| Cast range | **Casting** |
| Bite speed | **Attraction** |
| Hook window | **Precision** |
| Land Good/Bad | **Finesse** |
| Fish fight easier | **Stability** |
| Catch difficulty | **Control** |
| Rare finds | **Fortune** |
| Catch quality | **Quality** |
| Fishing XP | **Experience** |
| Second fish | **Double Catch** |

On a tooltip the number is first, then the stat in its colour, then where it works in purple: "+25% Attraction in jungles".

## Skills
What a piece does besides the stats now has a short name, in orange, with its chance when it has one. The tooltip lists the skills with the stats and explains each at the bottom in grey; the rod panel and the Angling Table's stats panel show the names, so you always know what your rod is doing.
- **Hot Line** (comes up cooked: the redstone line, the blazing rod), **Green Gold** (emerald hook), **Bottom Feeder** (stone hook), **Beekeeper** (Beeline), **Slime Trail** (mangrove rod), **Blossom** (cherry rod), **Scavenger** (rotten rod), **Forager** (grove rod), **Sunken Loot** (drowned rod), **Harvest** and **Green Thumb** (sickle rod), **Hex** (hex rod).
- Always on: **Fish Finder** (crystal rod), **Echo Sense** (echo rod), **Ender Sight** (ender eye bobber), **Midas Touch**, **Mentor** and **Bounty** (village rod), **Bonus XP** (diamond rod), **Hellfire** (blazing rod), **Lava Fishing**, **Void Fishing**, **Glow**, **Bell**, **Heartening** (heart bobber), **Barbed**, **Moonlit** (amethyst), **Night Hunter** (widow rod), **Far Reach** (wayfinder rod).
- Rig skills: **Sturdy** (Stone), **Swordfish** (Iron), **Gold Rush** (Gold), **Honey Pot** (Honey), **Sun Seeds** (Sunlight), **Moonshard** (Moonlight).

## Rod tooltips
- The rod's own tooltip no longer repeats its tackle's bonuses in a separate "Gear bonuses" list (the totals are already there).
