# Tide+ 1.0.16

Install the same way: the jar in `mods/` on the server and every client (replaces 1.0.15).

## Changes
- **Trophy and Mythic fish shimmer in your inventory.** A band of colour sweeps across the icon every couple of seconds: purple for Trophy, gold for Mythic. Raw and cooked fish both shimmer, vanilla fish too. The Mythic enchant glint is gone. Good and Great keep the corner mark.
- **No more sparkles on fish displays.** Mounted Trophy and Mythic fish sit still on the wall.
- **Place-and-time rigs are the best kit where they apply.** A full ocean, jungle, river, night, twilight, frost, storm, swamp, desert, cave, fire or void rig now adds luck, more catch quality and a chance to raise the catch a tier, so it beats the amethyst set in its place or time. Away from it, the amethyst set is still the best all-round kit (it is unchanged).
