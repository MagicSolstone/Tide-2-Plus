# Tide+ 1.1.4

Install the same way: the jar in `mods/` on the server and every client (replaces 1.1.3).

## Hover a stat or skill to see what it does
In the Angling Table's stats panel (and the tackle box's rig screen), each stat and each skill name can be hovered on its own. The tooltip shows the name and a line on what it does, so there's always somewhere to check what Fortune or Barbed does:

| Stat | What it does |
|---|---|
| **Casting** | How far your cast goes |
| **Attraction** | How soon a fish bites after the bobber lands |
| **Precision** | How wide the hook zones are when a fish bites, so it's easier to hook it well |
| **Finesse** | Your chance of still landing a fish you hooked Good or Bad, instead of losing it |
| **Stability** | How calmly a hooked fish fights: it darts around the catch bar less |
| **Control** | A bigger catch area on the catch bar, so the fish is easier to keep in it |
| **Fortune** | Luck: more rare fish and treasure |
| **Quality** | Shifts the odds toward better-quality fish |
| **Experience** | More fishing experience from each catch, so you level up faster |
| **Double Catch** | A chance to reel in a second fish of the same kind with the first |

Skills (Barbed, Hot Line, Green Gold, Fish Finder...) show the same text as at the bottom of their item's tooltip.
