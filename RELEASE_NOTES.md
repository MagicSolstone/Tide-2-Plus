# Tide+ 1.0.13

Install the same way: the jar in `mods/` on the server and every client (replaces 1.0.12).

## Changes
- **A progress bar to your next fishing level** in the rod stats panel (on the right while you hold a rod), with the percentage beside your level. It glides up when a catch lands.
- **Poor cod, salmon, tropical fish and pufferfish** (and cooked cod and salmon) now look dull too, like Tide's own fish.
